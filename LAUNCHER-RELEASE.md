# Blank Launcher 1.3.4

- При открытии лаунчер проверяет обновления перед показом библиотеки.
- Если новая версия доступна, показывается отдельный экран с ходом скачивания и установки. Лаунчер перезапускается автоматически.
- При ошибке скачивания обновление можно повторить с того же экрана.
- Если GitHub недоступен на этапе проверки, лаунчер сообщает об этом и открывает библиотеку.
