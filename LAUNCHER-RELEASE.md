# Blank Launcher 1.3.3

- Лаунчер автоматически скачивает и устанавливает обновление при открытии, затем перезапускается.
- Во время игры или установки сборки обновление само не начнётся.
- В настройках остаётся переключатель автообновления.
- Для перехода с 1.3.2 нажмите «Обновить» в самом Blank Launcher. Дальше обновления устанавливаются автоматически.
