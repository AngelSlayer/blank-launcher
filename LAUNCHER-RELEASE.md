# Blank Launcher 1.3.7

**Русский**

- В окне «Что нового» теперь можно прочитать до пяти последних ченджлогов сборки, начиная с установленной версии. Окно доступно во время игры.

**English**

- What's New now shows up to five recent modpack changelogs, starting at the installed version. The dialog stays available while Minecraft is running.
